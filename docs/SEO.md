# DDTC basic SEO — 6 November 2026

## Confirmed domain and initial live audit

The owner confirmed https://www.ddtctravels.co.za/ as the production URL. The live Chrome audit before these changes found `noindex, nofollow`, `Disallow: /`, an empty sitemap, no canonical URL, no Open Graph image, an unbranded homepage title and a default summary Twitter card. These were implementation defaults left over from internal preview.

## Implemented

- The confirmed production origin is the default for canonical URLs, social metadata, structured data and the sitemap. An invalid URL configuration fails clearly rather than producing malformed canonical URLs.
- Each public page has one branded search title, a descriptive meta description, a canonical URL, Open Graph metadata and a Twitter large-image card. Primary pages describe DDTC's services and its actual Rabokala/Brits location. Departure-specific Lesotho descriptions are distinct.
- All twelve trip pages use their own destination image and alt text for sharing. Contact query variants consolidate to `/contact` without losing enquiry prefills.
- The sitemap lists 19 canonical public URLs and twelve destination images. Legal drafts, APIs and enquiry query variants are omitted. No artificial modification dates are emitted.
- `/robots.txt` is generated by Next.js from `src/app/robots.ts`. `/llms.txt` provides a Markdown business summary, contact details, main page links and all twelve advertised trips, generated from the existing site/trip records at build time. It includes the enquiry and availability limitations, without presenting legal drafts as approved policies. It follows the [llms.txt proposal](https://llmstxt.org/) and does not replace robots rules or guarantee inclusion in AI answers.
- Normal production builds are indexable by default on the confirmed domain. `ALLOW_INDEXING=false` still disables indexing. Vercel preview/development builds and development mode stay noindexed even if the flag is true. All noncanonical request hosts receive `X-Robots-Tag: noindex, nofollow` as an additional safeguard.
- The non-www domain redirects permanently to the confirmed www host, retaining the path and query string. HTTPS and DNS/domain attachment remain hosting responsibilities.
- Draft privacy and booking pages retain noindex metadata but are not blocked in robots.txt, allowing crawlers to read that directive. Missing trips return 404/noindex.
- Business and website JSON-LD includes the actual name, legal name, address, telephone, email, canonical URL and supplied logo. Every trip has Home → Experiences → trip breadcrumb data. JSON-LD is safely escaped. No unconfirmed opening hours, coordinates, prices/availability offers or self-serving aggregate rating markup is added.

## Hosting and publication

Production settings:

```dotenv
NEXT_PUBLIC_SITE_URL=https://www.ddtctravels.co.za
ALLOW_INDEXING=true
```

Both values have suitable code defaults for the confirmed production site. An old hosting override of `ALLOW_INDEXING=false` must be removed or changed to true, followed by a fresh build/deployment. Keep the canonical domain the same in preview environments; Vercel's preview environment is automatically noindexed. On other staging platforms set `ALLOW_INDEXING=false` explicitly.

These source changes take effect after deployment. After deploying, check the live homepage's canonical/robots tags, `/robots.txt`, `/sitemap.xml`, a trip's social image/breadcrumbs and a draft legal page. The application-level apex redirect assumes both domains reach this Next.js project; configure the hosting primary domain as www as well.

The site owner should verify the domain in Google Search Console and submit https://www.ddtctravels.co.za/sitemap.xml after deployment. No Search Console ownership or sitemap submission has been performed in this task. A Google Business Profile can use the same confirmed business name, address, website and phone; profile ownership and any additional business facts still require the client's input.

The production build (including TypeScript), ESLint and all 18 tests pass. The production HTTP audit passed for all 19 public pages and all 19 sitemap URLs, with no errors. It covers unique titles/descriptions, destination social images, canonical URLs, public/draft robots directives, the apex redirect, noncanonical-host noindex headers and 404 behavior.
